📚 How Checksum Works

Sender Side

  1. Divide data into equal-sized segments
  2. Add all segments using binary addition
  3. If carry exists, add it back (wrap around)
  4. Take 1's complement → This is the Checksum
  5. Append checksum to data and transmit

Receiver Side

  1. Receive data segments + checksum
  2. Add all segments including checksum
  3. If carry exists, add it back (wrap around)
  4. Take 1's complement of the result
  5. If result is 0 → Data Valid ✅
  6. If result is non-zero → Error Detected ❌
